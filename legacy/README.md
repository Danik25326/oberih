# legacy/

Історичні прототипи. **Поточна мова живе в `../src/`.** Нічого звідси не збирається в CI,
не потрапляє в Docker-образ чи реліз.

- `python-prototype/` — перша повна реалізація на Python (`oberih.py run …`). Тут лежать
  речі, яких ще немає в Rust-версії: LSP-сервер (`lsp_server.py`) і VS Code-розширення
  (`editor/vscode-oberih`, воно запускає `../../lsp_server.py`, тому тека переноситься
  лише цілком). Корисно як довідка при портуванні LSP.
- `rust-prototype/` — найраніший прототип VM на Rust без залежностей (v0.1.0).

LSP уже портовано в Rust (`../src/lsp.rs`, `oberih lsp`), а нове розширення VS Code лежить у
`../editor/vscode-oberih/`. Python-прототип збережено як довідку; його історія доступна в git.
