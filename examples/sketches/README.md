# Ескізи (не запускаються)

Файли тут — **ескізи дизайну** з ранньої версії мови. Вони показують, як мала б виглядати
конфігурація стійкості (`idempotent`, `circuitBreaker`, `deadline`), але звертаються до
об'єктів, яких не існує в мові: `paymentGateway.charge(...)`, `weatherApi.get(...)`,
`agent.call(...)`. Перевірка імен (`oberih check`) справедливо повідомляє про них
«Невизначена змінна чи функція», тому вони винесені з `examples/`, де лежать лише робочі
приклади. Робочі приклади HTTP — `19_http.obh`, `28_https_smoke.obh`, `29_http_server.obh`.
